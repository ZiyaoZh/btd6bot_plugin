# 2026-10-12 上下文预算与持久记忆

状态：本地实现与离线验证完成，未部署、未重启生产进程。当前架构见 [ARCHITECTURE](../ARCHITECTURE.md)，配置与使用见 [README](../README.md)。

## 问题与选择

对 2026-10-07 至 2026-10-12 保留日志的只读评估覆盖 101 个任务、151 次成功 Agent 模型调用。供应商返回的 prompt token 中位数 14398、P95 28064、最大 217417。一份“巨齿鲨”详细数据节选达到 308984 字符；77 个任务带了历史图片但当前消息没有新图片。用户会话记忆中位数约 2389 字符，因此优先治理工具材料和历史图片，再补持久记忆。

同一时期存在接口超时、502 和模型切换，日志不足以将回答变差因果归结为长上下文。上下文大小、网络稳定性和回答质量需要分别验证。

当前采用“受预算约束的工作上下文 + 结构化摘要 + 可检索历史 + 显式持久记忆”的分层方式，复用 Harness 和 SQLite。暂未安装 Mem0、Letta、向量数据库或图服务；先建立来源、隔离、更新、删除和时效，再用实际召回失败决定是否引入语义索引。

## 实现边界

| 层次 | 行为 |
| --- | --- |
| 模型工作上下文 | 默认 24000 估算 token；计入 schema、消息及图片预留；每次 Agent 调用前执行 |
| 工具观察 | 默认按相关性节选；相同结果去重；保持 native assistant/tool 配对、provider 附加字段和原结果副本 |
| 知识读取 | 默认 8000 字符，有查询时取原文证据；无查询时分页；显式较大 `max_chars` 仍可完整读取 |
| 来源 | 知识节选携带原文件行范围/分页游标；通用观察节选只标内部行号，明确说明省略 |
| 摘要 | 超过 12000 字符触发；默认保留 6 轮；全部摘要字段合计最多 1200 字符；拒绝错误/无效摘要 |
| 摘要恢复 | 失败保留原记录并冷却 60 秒；积压按输入预算分批处理；未处理轮次继续保留 |
| 群窗口 | 默认最多 10 条、4000 字符、24 小时；优先最近和相关内容，按消息 ID 去重 |
| 历史像素 | 仅视觉诉求或显式引用启用；引用目标优先；当前附件优先；排除到期缓存 |
| 会话 | 以 `(group_id,user_id)` 隔离，默认持久化，重启懒加载恢复 |
| 历史检索 | 当前群当前用户的历史用户原文，默认近 90 天，最多扫描 200 轮；助手旧回答不升级为游戏事实 |
| 显式记忆 | preference/task/rule，用户原文来源、更新时间、过期时间；同 key 更新、forget 删除 |
| 记忆注入 | 自动最多 5 项、3000 字符；相关条目优先，无关偏好仅低权重补充；显式 search 只按查询匹配 |

文本使用 `tiktoken/o200k_base` 加 10% 余量，图片默认预留 2048 token。镜像构建预热 tokenizer 缓存；无法加载时使用 UTF-8 字节估算。代理模型 tokenizer、图片消耗可能不同，这不是实际供应商 usage 上限。当前问题、系统提示、工具 schema、provider 必需字段仍不能容纳时，停止调用并提示用户缩小本次问题范围。

## 持久化与变更事务

复用 `BOT_DB_FILE`，增加四张表：`agent_sessions`、`agent_turns`、`agent_memories`、`agent_memory_sources`。后者防止被纠正、删除、过期的显式记忆从原历史消息召回路径重新出现。每个群/用户归档最多 400 轮；历史淘汰在该会话提交时进行，恢复和召回也按时间过滤。过期显式记忆在提交时清理；关闭开关不会删除已有数据。

用户偏好和任务仅作用于当前群当前用户；共享写入要求事件身份为该群 owner/admin。`content` 必须逐字出现在当前用户消息中，并有明确记忆/偏好/任务意图；不自动从助手输出抽取事实。默认任务有效 7 天，其余 90 天，工具可设 1–365 天。

```text
模型调用 manage_memory -> 校验身份/来源/意图 -> 暂存变更
生成最终回复 -> 发送成功 -> SQLite 原子提交会话 + 归档 + 变更
```

发送失败或无回复时不提交，下一请求清除放弃的变更。交付后存储失败标记 `delivered_memory_failed`、提示未保存，保留 RAM 中已交付会话，丢弃待写显式记忆；避免出现“回复失败”误导或把失败变更写入下一轮。

`BOT_MEMORY_PERSISTENCE_ENABLED=false` 关闭持久层和记忆工具，继续使用预算与进程内会话；回退不需删除表。这里的 reset 指 Agent 会话 API：清理该群该用户的快照、历史、个人记忆和抑制记录，不删除管理员共享群规则。

## 验证

离线 unittest **143 项通过**，包括新增 **CG-01～CG-24**。覆盖原生工具配对、数组末尾/长行/小预算证据、表头与文件行号、压缩失败收敛、重启与隔离、记忆纠正/删除/过期、发送提交顺序、交付后落库失败、历史图片引用和积压摘要分批。完整规范和命令见 [测试索引](../tests/README.md)。

真实日志回放从 101 个任务中按大小均匀抽取 40 个任务，每个任务选最大一次请求；仅应用预算层，保留原有检索和历史图片，用同一估算器比较前后：

| 本地估算指标 | 改前 | 改后 |
| --- | ---: | ---: |
| P50 输入 token | 18309 | 17812 |
| P95 输入 token | 32099 | 23019 |
| 最大输入 token | 242465 | 23256 |
| 超过 24000 预算的请求 | 13 | 0 |

40 个请求均成功适配预算，总估算输入下降 **33.1%**；当前问题或 role/tool-call ID 序列变化 **0**。上表是本地 token 估算（含图片预留），与开头供应商实测样本的口径不同。回放不调用真实模型，未测输出准确率、线上时延或真实计费变化；历史图片筛选和新记忆层的效果通过合成回归验证，未计入该缩减比例。

## 已知限制与后续门槛

- 词项召回对中文同义表达、指代和跨主题关联能力有限；显式记忆扫描最近 100 项，历史扫描最近 200 轮，尚无向量召回。
- 明确引用优先级已实现，但只在取回的最近群窗口和用户会话中选择；不会按 ID 查找任意旧消息。
- 历史记录保留原文，模型摘要仍可能遗漏语义。显式记忆的意图/引用校验能限制写入，但“是否值得记住”的判断仍来自模型，并非完整事实验证器。
- 输入预算针对 Agent 主请求及会话摘要；独立视觉摘要、群消息总结等辅助模型请求仍沿用各自的限制。
- 尚未做真实模型回答质量 A/B、QQ 在线测试或新镜像构建/部署验收。上线时应固定模型等条件，观察 `context.budget` 的前后估算、实际 usage、重试、约束保留和回答正确性。
- 只有出现可复现的语义召回不足，再比较 FTS/BM25、向量混合召回或独立 memory 服务。现阶段不采用自动抽取大量“事实”再全量注入的方式。
