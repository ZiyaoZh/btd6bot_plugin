# 插件离线验证

从插件 `tests/` 目录运行，避免按包路径收集时触发插件入口对 NcatBot 的导入。

```bash
cd plugins/btd6bot_plugin/tests
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=.. python -m unittest discover -s . -p 'test_*.py' -q
```

测试使用临时 SQLite、Fake Model 和渠道桩，不调用线上模型、不发送 QQ 消息。需要插件依赖；缺少 NcatBot 时由既有测试桩提供渠道类型。2026-10-12 在独立 Python 3.12 环境中运行 **143 项通过**，其中新增上下文治理规范 **CG-01～CG-24**。

## 上下文规范索引

权威实现：[test_context_governance.py](test_context_governance.py)。CG 编号为插件上下文治理规范，不与 NcatBot 框架规范混用。

| 编号 | 要求 |
| --- | --- |
| CG-01 | 大工具结果保留问题相关的尾部证据、表头、原生调用 ID 和 provider 字段；原数据不变 |
| CG-02 | 相同工具结果正文去重，调用 ID 不变 |
| CG-03 | 预算计入 schema 和图片预留，不能静默裁掉当前问题 |
| CG-04 | 摘要保留轮数与历史窗口对齐，避免可见性断层 |
| CG-05 | 未摘要轮次不因短历史展示窗口而提前隐藏 |
| CG-06 | 空摘要、错格式及摘要故障均保留原历史 |
| CG-07 | 摘要全部字段的序列化总量有界，优先保留限制 |
| CG-08 | 重启恢复成功提交会话，群/用户隔离，reset 清理持久副本 |
| CG-09 | Agent 调记忆工具后，只在交付提交阶段持久化 |
| CG-10 | 放弃的暂存变更不被下一次请求带入数据库 |
| CG-11 | 显式来源、管理员群规则、纠正、删除及到期失效 |
| CG-12 | 长表格尾部检索保留标题/表头/文件行号，并能继续分页 |
| CG-13 | 无视觉诉求的普通文字不携带历史像素，视觉追问可使用 |
| CG-14 | 群窗口按时效筛选并与用户会话按消息 ID 去重 |
| CG-15 | prepare 摘要异常不阻断正常模型回复 |
| CG-16 | 超长单行和 160 字符小预算仍保留最具体命中的事实 |
| CG-17 | 超过 20 项的数组仍考虑末尾的相关项 |
| CG-18 | 长期摘要故障/旧版大摘要可削减工作上下文至预算内 |
| CG-19 | 每档从原观察选取；观察片段行号不冒充原文件行号 |
| CG-20 | 查询任务优先于无关偏好；显式搜索支持 key |
| CG-21 | 默认无查询知识读取返回可推进的原文件页码 |
| CG-22 | 交付后存储失败有独立状态与未保存提示，保留 RAM 会话 |
| CG-23 | 结构化回复引用及视觉追问优先目标图，排除过期像素 |
| CG-24 | 超预算积压历史分批摘要，仅替换模型实际处理的部分 |

既有 Agent 工具测试保留显式完整读取 60k 字符/5000 行知识材料的断言；默认读取策略与完整读取能力分别验证。其余测试覆盖工具编排、交付事务、产物、知识搜索和图片链路。

## 真实请求离线回放

在部署仓库根目录执行：

```bash
PYTHONDONTWRITEBYTECODE=1 python plugins/btd6bot_plugin/tests/evaluate_context_budget.py \
  --logs runtime/plugin/logs --since 2026-10-07 --limit 40 \
  --output /tmp/btd6-context-replay.json
```

脚本读取本机已有脱敏请求日志，每个任务保留最大一次请求，再按请求大小均匀抽样；只输出汇总统计，不打印聊天正文。只应用预算层，保留原检索和历史图片输入，检查当前问题和 role/tool-call ID 序列不变。**不联网、不重新生成答案，不能衡量模型回答质量。** 结果及测量限制见 [评估记录](../memory/2026-10-12_context_budget_and_persistent_memory.md)。
