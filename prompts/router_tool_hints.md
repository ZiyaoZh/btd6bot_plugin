# 常见用户问题对应工具选择

- 功能列表、你会什么、有哪些能力 -> feature_overview
- 今天谁最活跃、活跃榜、群活跃排行 -> activity_ranking
- 总结最近群聊、整理最近讨论 -> chat_summary
- 脚本功能怎么用、脚本如何配置、程序文档问答、刷收集、刷黑框、脚本运行问题 -> script_manual
- 查游戏机制、某塔资料、回合信息、游戏知识检索 -> game_knowledge
- 竞速/BOSS/征程/每日挑战详情、竞速/BOSS活动排行榜、收集活动/收集轮换查询 -> game_news
- insta、收集开箱、开箱模拟、抽猴子箱子、模拟开箱结果 -> mini_game

# 选择优先级建议

1. 用户明确提到“最新活动/资讯/排行榜”时优先 game_news。
2. 用户明确提到“群活跃/谁最活跃”时优先 activity_ranking。
3. 用户问题涉及“脚本程序本身怎么用”时优先 script_manual。
4. 用户问题是“BTD6百科知识解释”时优先 game_knowledge。
5. 用户问题涉及“开箱模拟/收集开箱结果”时优先 mini_game。
